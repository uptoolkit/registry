Admin page built around [`crud-data-table`](/blocks/crud-data-table).

```bash
npx shadcn@latest add @_cn/crud-admin-page
```

Installs to `app/admin/page.tsx` with the table block, hook, helpers, and sample
book columns.

Point the table at a live API Platform collection by editing
`CrudAdminPageContent`:

```tsx
<CrudDataTable endpoint="/api/books" manual heading="Books" />
```

The page stays a server component; only the table runs on the client.
