Types and helpers shared by the data table components and
[`use-crud-data-table`](/hooks/use-crud-data-table).

```ts
import { dataTableStateToCrudQuery, defaultDataTableState } from "@/lib/data-table-helpers";

const query = dataTableStateToCrudQuery(state, columns);
```

### Column meta

Attach filters and labels through `columnDef.meta`:

```ts
meta: {
  label: "Status",
  filter: {
    type: "multiselect",
    operator: "in",
    options: [
      { label: "Draft", value: "draft" },
      { label: "Published", value: "published" },
    ],
  },
}
```

Supported filter types: `text`, `select`, `multiselect`, `boolean`, `date`.
