Platform metadata and URL helpers for external social profiles. Built-in support for
**Facebook**, **LinkedIn**, and **Grok**, with room to extend the registry at runtime.

```ts
import {
  buildSocialNetworkUrl,
  detectSocialNetwork,
  getProfileUsername,
  socialProfilesFromPropertyValues,
} from "@/lib/social-networks";

detectSocialNetwork("https://www.linkedin.com/in/ada"); // "linkedin"
buildSocialNetworkUrl("grok", "@mira_maps"); // "https://grok.com/@mira_maps"
socialProfilesFromPropertyValues(actor.attachment ?? []);
```

`SocialNetworkProfile` is the data contract consumed by
[`social-network-link`](/components/social-network-link) and
[`user-social-networks`](/components/user-social-networks). Pass `verified: true`
when a link has been confirmed, matching Mastodon's `verifiedAt` on
`PropertyValue` rows.
