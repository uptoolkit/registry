Wraps `useReactTable` with row selection, column visibility, global search, and
API Platform query mapping.

```tsx
import { useCrudDataTable } from "@/hooks/use-crud-data-table";

const { table, query } = useCrudDataTable({
  columns,
  data: books,
  manual: true,
  rowCount: totalItems,
  onQueryChange: (query) => fetchBooks(query),
});
```

Set `manual: true` when the collection is fetched from an API Platform endpoint.
`query` always reflects the current table state and can be passed to
`buildApiPlatformQuery` or `fetchApiPlatformCollection`.
